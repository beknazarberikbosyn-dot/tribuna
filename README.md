# Трибуна

Тренер по постановке речи. Вставьте текст выступления или запишите его голосом, и Gemini разберёт речь: поставит оценки, отметит слабые места прямо в тексте и покажет, как сказать лучше.

## Что умеет

- Разбор текста: можно вставить его или загрузить файл `.txt`.
- Разбор записи с микрофона до 10 минут: Gemini сам расшифровывает речь и оценивает подачу (темп, паузы, интонацию).
- Оценки по структуре, ясности, убедительности, языку и подаче.
- Слабые стороны с цитатой из речи, объяснением, способом исправить и примером новой формулировки.
- Пометки в тексте: замечания выделены жёлтым, возможные слова-паразиты подчёркнуты.
- Темп речи и счётчик слов-паразитов считаются в браузере, без ИИ.
- Разбор на русском, казахском или английском.

## Запуск на компьютере

Нужен Node.js 18 или новее. Зависимостей нет.

1. Получите ключ Gemini API в [Google AI Studio](https://aistudio.google.com/apikey).
2. Скопируйте `.env.example` в `.env` и вставьте ключ в `GEMINI_API_KEY`.
3. Запустите:

```bash
npm run dev
```

Сайт откроется на http://localhost:3000. Микрофон в браузере работает только на `localhost` или по HTTPS.

Проверить вёрстку разбора без ключа можно на странице http://localhost:3000/?demo.

## Публикация на Vercel

1. Импортируйте репозиторий в Vercel (Framework Preset: Other, настройки сборки менять не нужно).
2. В Settings → Environment Variables добавьте `GEMINI_API_KEY`. При желании задайте `GEMINI_MODEL`.
3. Нажмите Deploy.

Папка `public/` раздаётся как статика, а `api/analyze.js` работает как серверная функция. Ключ остаётся на сервере и в браузер не попадает.

## Устройство

| Файл | Назначение |
| --- | --- |
| `public/index.html`, `styles.css` | Страница и оформление |
| `public/app.js` | Ввод текста, запись голоса, показ разбора |
| `public/metrics.js` | Подсчёт слов, темпа, слов-паразитов, пометки в тексте |
| `lib/gemini.js` | Проверка запроса, промпт, обращение к Gemini |
| `api/analyze.js` | Серверная функция Vercel |
| `dev/local-server.js` | Локальный сервер для разработки |
| `vercel.json` | Настройки Vercel: статика из `public/`, функции из `api/` |
| `test/` | Тесты (`npm test`) |

## Ограничения

- Текст до 20 000 символов, запись до 10 минут (тело запроса на Vercel ограничено 4,5 МБ).
- Модель по умолчанию `gemini-3.8-flash`. Если она недоступна для вашего ключа, укажите другую в `GEMINI_MODEL`.
- Список слов-паразитов простой, поэтому счётчик показывает «возможные» слова-паразиты: «вот» или «значит» иногда стоят по делу.
